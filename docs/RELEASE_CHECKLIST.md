# Public Release Checklist

- [ ] Root README reflects the current research state and separates primary results from prototypes/archive work.
- [ ] `docs/RESEARCH_INDEX.md` points to the canonical evidence and states claim boundaries.
- [ ] Upstream provenance and contribution boundaries are current.
- [ ] Build/test commands shown in public docs are repository-relative and verified against tracked files.
- [ ] Failed/superseded research material required for provenance remains traceable.
- [ ] No credentials, new machine-specific absolute paths, raw bulk artifacts, or OS metadata are introduced.
- [ ] License and citation metadata are present and upstream licenses remain intact.
- [ ] The public tag/release points to a reviewed commit.
