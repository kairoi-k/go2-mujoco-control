## 本轮结论

值得进入最小联合规划，但不应该把“换成联合优化就会跨过去”当成已经证明的结论。H9 定位了新计划被拒绝、旧计划到期的直接链条；它没有证明拒绝全部源于逐腿贪心，也没有证明下游已经可靠。

这次额外找到三类会直接影响设计的代码事实：shadow 时支撑锚点的采集仍被 actuation 开关挡住；传感器世界缓存有有限边界，地图结构有效不代表仍有观测；所谓安全“区域”在当前 5cm 网格与 2.5cm 足底半径下几乎退化为点。另有冻结分析器的 transfer 最少两接触要求，与包含腾空段的小跑预测存在条件冲突。详见审计报告，均不能绕过验收解决。
