## Timebase and missing evidence
Both raw streams use `state_tick_s`/ground-truth `time_s` on the same simulator-time scale. The current run records `motion_clock_wall_mode=0`; historical metadata explicitly passes `--wall-clock-motion` and records mode `1`. Consequently `cmd_time_s` differs by about `0.312 s` at state 23.632 even though `state_tick_s` matches. The report keeps state-time and x-time comparisons separate and does not attribute the failure to this mode.
To identify the actual geom and first controller-side contact decision, the next bounded run needs per-contact geom ids/names (or an equivalent named classification) and a cycle-level attempt/selected/fallback/cache record. Existing CSVs can establish contact-force timing, body state, commands, plan validity, and WBC status, but cannot establish the geom identity or prove a capture-view/clock cause.
