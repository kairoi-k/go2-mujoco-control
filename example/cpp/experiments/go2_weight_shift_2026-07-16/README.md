# Go2 前右脚抬升前的重心转移实验

日期：2026-07-16

## 目的

在暂不抬脚的条件下，让机身向左后方平移，验证前右脚是否卸载，并选择后续抬脚实验的重心转移基准。

## 方法

控制流程：

1. 不发送控制命令，等待机器人自然趴稳；以关节速度和 IMU 角速度持续低于阈值 `0.5 s` 为判据。
2. 从自然趴稳时测得的 LowState 直接连续站起 `3 s`。
3. 完全站立后稳定 `0.5 s`。
4. 假设四脚保持地面接触，将四脚在 `base_link` 中的目标坐标相对向右前方平移。
5. 用逆运动学求出 12 个关节目标，并用 smoothstep 在 `2 s` 内完成机身左后移。
6. 记录足底力、IMU、足端位置和关节数据。

比较三组机身目标位移：

- 后移 `1 cm`、左移 `1 cm`
- 后移 `2 cm`、左移 `1.5 cm`
- 后移 `3 cm`、左移 `2 cm`

## 结果

| 目标位移（后/左） | 估计实际位移（后/左） | FR 稳定站立力 | FR 转移后力 | FR 卸载 | 保持段最大 roll/pitch |
|---|---|---:|---:|---:|---:|
| `1 / 1 cm` | `1.09 / 1.01 cm` | `36.00` | `33.55` | `6.8%` | `0.12° / 0.37°` |
| `2 / 1.5 cm` | `2.22 / 1.51 cm` | `36.00` | `30.53` | `15.2%` | `0.15° / 0.39°` |
| `3 / 2 cm` | `3.36 / 2.02 cm` | `36.00` | `28.08` | `22.0%` | `0.15° / 0.34°` |

三组均能稳定完成，位移越大，前右脚受力越低。当前扫描中，后移 `3 cm`、左移 `2 cm` 的卸载效果最明显，机身姿态变化仍较小。

## 结论

先采用“后移 `3 cm`、左移 `2 cm`”作为前右脚抬升实验的重心转移基准。

这还没有完全卸载前右脚，其足底力仍约为稳定站立时的 `78%`。下一步应在该姿态上只抬升很小高度，并继续监测 FR 足底力是否接近零以及机身是否稳定；不能直接进行大幅抬脚。
