# Go2 FR 单步前进

日期：2026-08-02

## 目的

验证一个完整单步原语：重心转移、抬腿、足端前摆、接触落脚、机身前移和终点保持。

## 参数

- 目标腿：FR
- 重心转移：后移 7 cm、左移 6 cm
- 足端：抬升 4 cm、前摆 10 cm
- 落脚后机身前移：5 cm

## 复现实验

从仓库根目录运行：

```bash
example/cpp/scripts/run_single_step.sh 35 go2_single_step_fr_forward_body_advance_2026-08-02 FR
```

脚本默认使用上述抬升、前摆和机身前移参数，并在实验结束后自动生成汇总表和总览图。

## 实测结果

| 指标 | 结果 |
|---|---:|
| 足端实际前摆 | 96.7 mm |
| 机身世界坐标净前移 | 38.3 mm |
| 摆动期间世界净空均值 | 19.4 mm |
| 落脚检测 | FR 足底力达到 5 N |
| 最大绝对 roll / pitch | 1.14° / 1.19° |
| 支撑脚最大漂移 | 12.4 mm |

## 文件

- `data.csv`：原始控制与状态记录。
- `single_step_summary.csv`：指标汇总。
- `single_step_overview.png`：足端、接触、机身位移和姿态曲线。
- `controller.log`、`simulator.log`：运行日志（不在 git）。

## 结论

该实验完成了“抬脚并前移”的单步闭环。它还不是连续步态；下一步要把该原语接成对角换腿序列，并用世界位移校准多步前进距离。
