# Go2 站立跟踪 Kp 参数扫描

- 日期：2026-07-07
- 状态：accepted（早期 PD 基准）
- 目的：为后续四肢动作实验选择稳定、误差较小的站立 PD 参数。

## 配置与证据

固定 `kd=3.5`，比较 `kp=30/50/80/100`；各组原始 CSV 和图片在同名参数子目录。

## 结果

`kp=30` 刚度不足；`kp=50/80/100` 可站立，后 2 s 平均误差分别约 `0.0918/0.0600/0.0421 rad`；当前动作实验基准取 `kp=100,kd=3.5`。

## 限制

仅扫描了 Kp，未系统比较 Kd、速度和力矩峰值；后续 trot 使用独立的低增益/WBC 基线，不应把本实验参数直接当成最终步态参数。
