# Go2 前右腿周期屈伸实验

- 日期：2026-07-07
- 状态：accepted（原语验证；不是严格抬脚）
- 目的：验证站立基准下单腿关节命令能否连续跟踪。

## 配置与结果

仅改变 FR thigh/calf，幅值 `0.20 rad`、频率 `0.5 Hz`；两关节均能跟踪，但四脚仍接触地面，机身出现摇摆。

## 结论

这是“前右腿周期屈伸”，不是“三腿支撑、前右脚离地”。后续正式抬脚实验需先做重心转移，并协调 hip/thigh/calf 或直接采用足端轨迹 + IK。

详细原始证据：本目录的 `data.csv`、`error.png`、`target_state.png` 及同名说明文件。
