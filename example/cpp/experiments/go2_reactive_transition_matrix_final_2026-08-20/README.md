# Reactive transition matrix

Generated by `run_reactive_transition_matrix.py`. Each run changes only the two-line event script; controller gains, scene, gait parameters, and WBC/MPC code path are held constant. Emergency stop is an absorbing safety state and is only tested as a destination by default.
Result: all 49 directed transitions passed the shared acceptance gates; see reports/transition_matrix_report.md and reports/transition_matrix_metrics.json.
Reproduce from the repository root with run_reactive_transition_matrix.py and then analyze_reactive_transition_matrix.py using the same matrix directory and the documented 1.5 s event start, 2.0 s event duration, and 8.0 s controller duration.
Raw per-run CSV and simulator logs are intentionally ignored by Git and retained in the local/evidence bundle; protocol manifests, event scripts, runner results, and reports remain versioned. This matrix validates scripted reference transitions; automatic perception is validated separately by the scene-level environment-acceptance report.
